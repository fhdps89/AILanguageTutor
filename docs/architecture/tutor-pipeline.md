# 🧠 AI 어학 튜터 프롬프트 파이프라인 & 멀티모달 분석 설계서

## 1. 개요
교재나 원서 사진을 입력받아 고정밀 OCR을 수행하고, 감지된 언어에 따라 맞춤형 학습 데이터를 생성하는 백엔드 파이프라인 구조입니다.

---

## 2. 멀티모달 분석 파이프라인 (`server.ts`)

### 2.1 입력 처리 (Input Preprocessing)
- 모바일 캔버스에서 장변 3,000px(JPEG 품질 0.88)로 압축된 이미지를 멀티파트(`multer`)로 수신.
- Base64 인라인 데이터로 변환 후 Gemini 멀티모달 프롬프트 구성.

### 2.2 모델 사양
- **모델:** `gemini-3.8-flash`
- **구조화된 출력 (Structured Output):** JSON Schema 엄격 강제 (`responseMimeType: "application/json"`)

---

## 3. 양방향 튜터링 라우팅 (Bilingual Routing Engine)

```
[교재 이미지 수신]
        │
        ▼
[Gemini Vision 멀티모달 판독]
        │
        ├─► 언어 코드: 'ko' (한국어 원서)
        │       └─► K-Language 역방향 학습 데이터 생성
        │             • 자연스러운 영어 번역
        │             • 음운 동화 반영 단일 소리 로마자 (One Phonetic Romanization)
        │             • 문법 청크 (조사/어미 분해: Topic/Subject/Possessive)
        │             • 엄격한 격식도 배지 (합쇼체/해요체/해체, 서술체는 null)
        │             • 사전 원형(baseForm) 어휘 추출
        │
        ├─► 언어 코드: 'zh-CN', 'zh-TW' (중국어 원서)
        │       └─► 중국어 쉐도잉 특화 학습 데이터 생성
        │             • 성조(1~4성) 표기 표준 한어병음(Hanyu Pinyin) 라인
        │             • 성조 변조 팁(3+3->2+3, 不/一 변조, 권설음, 경성)
        │             • 성조·의미 청크 끊어 읽기(/) 및 ASCII 주술목 구문도
        │             • 단어별 병음 배지 및 어휘 사전
        │             • CJK 음소 단위 60fps 노래방 칼싱크
        │
        └─► 언어 코드: 기타 외국어 (fr, en, ja, es, de 등)
                └─► 내국인 대상 외국어 학습 데이터 생성
                      • 자연스러운 한국어 번역
                      • 슬래시(/) 끊어 읽기 호흡 마크
                      • ASCII 구문 분석도 (Syntax Tree)
                      • 핵심 어휘 및 뉘앙스 해설
```

## 4. 프롬프트 안전성 및 노이즈 방어

1. **뒷면 비침(Ghosting) 방어:**  
   종이가 얇아 뒷면 활자가 비치는 경우 이를 OCR 대상에서 엄격히 배제하도록 지시.
2. **각주 별표(`*`) 정제:**  
   `FOMO*`와 같은 인쇄용 각주 표기 기호는 본문 문장에서 제거하여 자연스러운 발화 유도.
3. **페이지 절단 문장 안전 마감:**  
   페이지 하단에서 문장이 끊겼을 때 임의로 문장을 창작하거나 환각(Hallucination)하지 않고 실제 인쇄된 지점까지만 안전하게 닫음.
