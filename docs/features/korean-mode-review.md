## 1. 저장소 기준 분석 요약
외국어 모드와 한국어 모드의 공통 파이프라인 활용:
- `language.code === "ko"`로 카드 렌더링 분기.
- TTS는 동일한 `gemini-3.8-flash-lite-tts`, 목소리 `Kore` 사용.
- 캐시 키 `SHA-256(text + "_" + lang + "_" + voice + "_" + speed)`로 언어별 완벽 분리.
- 문장 릴레이, 해시 음성 주소, WAV 스트리밍, 중복 요청 방지 파이프라인 100% 재사용.

## 2. 유지할 원칙
- 모델 `gemini-3.8-flash-lite-tts` 유지. 느린 음성은 브라우저 배속이 아니라 LLM 스타일 지시 (0.75x 여유 템포, 0.5x 또박또박).
- 카드의 알맹이는 소리 로마자, 영어 번역, 조사·어미 청크, 종결이 있을 때만 격식 배지, 동사 기본형.
- 입력 가정은 책, 잡지, 신문 등 실전 인쇄물.

## 3. 핵심 방어 포인트
1. **모드 토글 불필요:** 본문 글자가 한글이면 한국어 카드, 아니면 외국어 카드 자동 적용.
2. **외래어 오판 방지:** 인용 한 줄, 고유명사, `FOMO` 한 단어로 인해 언어 모드를 오판하거나 확인 창을 띄우지 않음.
3. **소리 로마자 단일화:** Revised Romanization과 실제 발음을 혼용하지 않고, 실제 귀에 들리는 소리 기준으로 1개만 표기.
4. **격식 배지 조건부 표기:** 확실한 종결어미가 있을 때만 표기하며, 서술체(`~다`)는 중립 처리(`null`).
5. **광학 노이즈 제거:** 뒷면 비침 무시, 각주 별표(`*`) 제거, 잘린 문장 마감 처리.
