# 현재 화면과 동작 (2026-10-09 기준)

화면 리뉴얼(R1~R11, C4, C5, B1)을 끝낸 뒤의 모습입니다. 단계별 상세와 확인 기록은 `docs/history/changelog.md`의 2026-10-09 항목을 봅니다.

## 시작 화면 (열린 수업이 없을 때)

위에서 아래로: 한 줄 소개(「책을 사진 찍으면 문장별로 읽어 주는 앱」)와 지원 언어 안내 → 예시 영상 → 「내 책 올려 보기」 → 「카메라로 바로 촬영하기」 → 「오늘 사진 N장 남음」 → 「내 서재에서 이어 하기」(내 수업이 있을 때만) → 「사진과 저작권 안내」(접힘) → 사용 기록 안내 한 줄.

- 예시 영상(`LandingDemoVideo.tsx`, 파일은 `public/landing/`): 소리 없이 반복, 4:5, 화면 밖에서는 멈춤, 일시 정지 버튼(44px). 「동작 줄이기」 설정이면 대표 이미지와 「예시 영상 보기」(한 번만 재생). 자동 재생이 막히거나 파일을 못 읽으면 대표 이미지만 보인다.
- 처음 온 기기에서는 예시 수업을 자동으로 열지 않고, 내 수업이 있으면 가장 최근 것을 연다.
- 사진을 고르기 전에는 업로드 칸이 숨겨져 있고, 고르면 「선택한 사진」 칸(생성 버튼 포함)이 나온다. 오늘 사진 한도를 다 쓴 날은 시작 화면 대신 안내 카드가 나온다.

## 서재와 데모

- 「내 서재」 버튼은 어디서나 보이고, 휴대폰에서는 아래에서 올라오는 시트다. 서재에는 내가 올린 수업만 있다(예시 수업 제외).

## 수업 화면: 문장 카드

문장마다 한 줄(높이 60px 이상: ▶, 번호, 문장 앞부분)만 보이고, 누른 줄만 펼쳐지며 바로 재생된다. 펼친 줄에는 위에서 아래로 정지/재생 버튼과 상태, 원문(읽는 단어가 파랗게 따라감)·병음, 진행 막대(처음 듣는 음성은 같은 자리에 로딩 상자), 「듣기 속도」 세 칸(1.0x 보통 / 0.75x 쉐도잉 / 0.5x 조음 훈련), 번역, 「끊어 읽기」 칩(누르면 그 부분만 1.0x로), 접이식 「구문 분석도」·「핵심 어휘」(연음/성조 팁은 어휘 아래), 「이 설명이 틀렸어요」 신고가 있다.

- 속도 칸을 누르면 같은 문장을 그 속도로 처음부터 다시 재생하고, 고른 속도는 다음 문장에도 이어진다.
- 브라우저는 항상 `playbackRate = 1.0`으로 재생한다. 느린 음성은 서버가 만든 것이다.
- 수업 화면 위에는 업로드 칸이 없고, 맨 아래 「전체 연속 듣기」 아래에 「새 책 올려 보기」가 있다.
- 카드 안 글자는 12px 이상, 누르는 칸은 44px 이상이다.

## 2026-10-09에 정한 것

- 느린 속도는 서버가 만든 음성을 쓰고 `playbackRate`·미리 받기는 쓰지 않는다. 칩 부분 듣기는 1.0x 고정.
- 이름은 「끊어 읽기」. 서재는 내 수업만. 영상은 카드 개편 뒤 실제 화면으로 제작.
- 첫 화면 지원 언어에 중국어를 포함한다(일본어 품질은 미확인).
- 실패한 분석도 사진 한도를 차감한다(면제는 보류).
