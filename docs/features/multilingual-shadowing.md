# 🌐 다국어 쉐도잉 학습 시나리오 및 기능 명세서

## 1. 개요
외국어(프랑스어, 영어, 일본어, 스페인어, 독일어, 중국어 등) 원서 및 교재를 학습하는 한국인 학습자를 위한 핵심 학습 시나리오 및 UI/UX 인터랙션 명세입니다.

---

## 2. 핵심 학습 인터랙션

### 2.1 끊어 읽기 모드 (Chunk Mode)
- **목적:** 장문 독해 시 원어민식 의미 덩어리 호흡 습득.
- **표현:** 문장 내 슬래시(`/`) 기호로 청크 경계 구분.
- **인터랙션:** 청크 텍스트 터치 시 해당 구문만을 즉시 발음하여 귀로 확인.

### 2.2 어휘 강조 모드 (Vocab Mode)
- **목적:** 문맥 속 핵심 단어의 사전적 의미와 뉘앙스 파악.
- **표현:** 주요 어휘 하이라이트 배지.
- **인터랙션:** 어휘 터치 시 툴팁(한국어 뜻, 품사, 어원/발음 힌트) 노출 및 원어민 단어 발음 재생.

### 2.3 ASCII 구문 분석도 (Syntax Tree)
- **목적:** 복잡한 문장 구조(주어, 동사, 목적어, 수식절)의 시각적 해체.
- **UI:** 모바일 스크롤 부담을 줄이기 위해 접이식 아코디언 토글 적용.

### 2.4 실시간 60fps 노래방 싱크 (Karaoke Highlighting)
- 전체 지문 낭독 또는 문장 재생 시 현재 발화 중인 단어가 실시간 파란색으로 하이라이트.
- Zero Layout Shift: 원문 레이아웃(Serif 서체, 줄바꿈, 띄어쓰기)을 변경하지 않고 시각적 강조만 부드럽게 전환.

### 2.5 "내일은 여기서부터 시작" 북마크 & 이어하기
- 문장 카드 우상단 북마크 아이콘 클릭 시 로컬 스토리지에 해당 문장 ID 영구 저장.
- 골드 하이라이트 테두리 및 뱃지 표시.
- 재접속 시 최상단 [바로 이어하기] 배너 클릭으로 해당 위치 스크롤 및 펄스 포커스.

### 2.6 중국어(Mandarin) 전용 쉐도잉 특화 기능
- **표준 한어병음(Hanyu Pinyin) & 성조 표기:**
  - 원문 한자 바로 아래에 1~4성 성조 기호가 포함된 정확한 병음 라인 노출 (`Běijīng Gùgōng...`).
- **성조 변조(Tone Sandhi) 및 발음 팁:**
  - 3성 변조(3+3 -> 2+3), 不/一의 성조 변화, 권설음(zh/ch/sh/r) 조음 위치, 경성 처리를 안내하는 `🗣️ 성조/발음 팁` 배지 제공.
- **성조·의미 청크 끊어 읽기:**
  - 띄어쓰기가 없는 한자 텍스트의 호흡을 살린 `/` 단위 청크 분해 및 터치 즉시 발음 청취.
- **CJK 음소 단위 노래방 칼싱크:**
  - 한자 1글자=1음절의 어쿠스틱 타이밍을 정밀 계산하여 발화와 동시에 글자가 점등되는 60fps 싱크.
